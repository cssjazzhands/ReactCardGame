# Bug Collector (ReactCardGame)

## Description

A simple game about logging in daily, performing tasks, and building a collection of bugs by purchasing card packs with in-game currency.

## Tech stack versions

This uses a boilerplate that integrates React, Vite, Express, and TypeScript. This setup provides a robust development environment with hot module replacement for the frontend and an efficient build system for both frontend and backend.
